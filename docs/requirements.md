# 運動と痛みの記録アプリ 要件定義書（ドラフト v0.5）

作成日: 2026-11-10（v0.2: 確認事項への回答を反映 / v0.3: 強度・痛んだ動き・入力補助・グラフ追加 / v0.4: 強度を 5 段階に変更 / v0.5: 痛んだ動きを痛みの部位とセットで記録）
対象: 個人利用（利用者 1 名、ログインなし）

---

## 1. 目的

臼蓋形成不全による股関節まわりの痛みが「どの運動で」「どのタイミングで（運動前・中・後・翌日）」「どの部位に」出やすいかを把握する。
日々の記録をカレンダーとグラフで見える化し、運動の選び方や強度調整、通院時の説明に役立てる。

## 2. 前提・制約

| 項目 | 内容 |
|---|---|
| 利用者 | 本人のみ。ログイン・ユーザー管理は不要 |
| 費用 | 作成・公開・運用すべて無料で行う |
| 端末 | スマートフォンのみ（1 台）。複数端末の同期は不要 |
| PWA | ホーム画面に追加でき、オフラインでも記録・閲覧できる |
| 画像 | 扱わない |
| 起動時画面 | カレンダー（月表示） |

## 3. 用語の定義

| 用語 | 意味 |
|---|---|
| 運動記録 | 1 回のジム滞在・外出など「続けて行った運動のまとまり」。運動前の痛み・運動後の痛みは 1 記録に 1 回だけ |
| 運動（アクティビティ） | 運動記録の中の 1 種目。種類・時間・運動中の痛みを持つ。1 記録に複数持てる |
| 痛み記録 | 運動していない日、または運動とは別のタイミング（起床時など）の痛みだけを記録したもの |
| 痛みセット | 「部位・左右・程度」の組。1 つのタイミングに複数追加できる |

### 3.1 「続けて行った運動」と「別の記録」の判断基準

ユーザーの迷いを減らすため、アプリ内に次の目安を表示する。

- **同じ運動記録に「続けて追加」**: 種目の間の休憩が 30 分未満（例: ボディアタック → ボディパンプを連続で受講）
- **別の運動記録として登録**: 30 分以上空いた、いったん帰宅した、午前と夜に分けて行った
- 目安の分数は設定で変更可能（初期値 30 分）
- 開始時刻（任意入力）を持たせ、後から見ても区別できるようにする
- **開始時刻を入れなくても別の記録は作れる**。「＋ 運動を記録」は押すたびに新しい記録を作る
- 新規入力時、その日にすでに運動記録がある場合は「○件目の記録として保存されます」と表示し、「前の記録に続けて追加する」ボタンを出す

## 4. 機能要件

### 4.1 運動記録の登録・編集・削除

| 項目 | 入力方法 | 必須 | 備考 |
|---|---|---|---|
| 日付 | 日付選択 | ○ | カレンダーから開いた場合はその日付を初期値にする |
| 開始時刻 | 時刻選択 | − | 同じ日の複数記録の区別用 |
| 運動前の痛み | 痛みセット（4.4） | − | 「痛みなし」ボタンあり |
| 運動（複数可） | 下表 | ○（1 件以上） | 「＋ 続けて別の運動を追加」で増やす |
| 運動後の痛み | 痛みセット（4.4） | − | 「痛みなし」ボタンあり |
| メモ | 自由入力（複数行） | − | |

運動ごとの項目:

| 項目 | 入力方法 | 必須 | 備考 |
|---|---|---|---|
| 種類 | プルダウン（初期値は未選択） | ○ | ボディコンバット / ボディアタック / ボディパンプ / ボディステップ / 卓球 / バドミントン / ヨガ / ランニング / 登山 / プール / その他 |
| 種類（その他） | テキスト | その他選択時 ○ | 一度入力した名称は次回から候補に出す |
| 運動時間 | 数値（分）＋よく使う時間のボタン（30 / 45 / 55 / 60 / 90 分） | ○ | 初期値は空欄。種類を選ぶとその種類の標準時間を入れる |
| 強度 | 5 段階のボタン選択（4.1.1） | ○ | 初期値「3 ふつう」。選んだ段階の目安を下に表示する |
| 運動中の痛み | 痛みセット（4.4） | − | 「痛みなし」ボタンあり |

#### 4.1.1 強度の 5 段階

| 段階 | 名前 | 目安 |
|---|---|---|
| 1 | かなり抑えめ | ローインパクト中心、ジャンプなし |
| 2 | 少し抑えめ | 一部の動きだけ控えた |
| 3 | ふつう | いつも通り |
| 4 | しっかり | いつもより頑張った |
| 5 | 全力 | 限界まで出し切った |

5 段階で記録しておけば、後から 3 つにまとめて見ることもできる（3 段階で記録すると後から細かく分けられない）。

**入力補助**
- **よく使う組み合わせ**: 新規入力の先頭に「前回と同じ」と、よく記録する組み合わせ（例: BA 55分 → BP 60分）を最大 4 つ表示し、タップで運動欄に入れる。痛みと強度は入れない
- **過去の傾向**: 運動の種類を選ぶと、その種類の過去の平均（運動中 / 運動後 / 翌日・回数）を表示する

### 4.2 痛みのみの記録の登録・編集・削除

| 項目 | 入力方法 | 必須 | 備考 |
|---|---|---|---|
| 日付 | 日付選択 | ○ | |
| タイミング | ボタン選択: 起床時 / 日中 / 就寝前 / その他 | ○ | 「翌日の痛み」の集計に使う |
| 痛み | 痛みセット（4.4） | ○ | 「痛みなし」も 1 つの記録として残せる |
| メモ | 自由入力 | − | |

- 運動した日でも登録できる（例: 運動した日の就寝前、翌朝の起床時）
- 1 日に複数件登録できる

### 4.3 カレンダー

- 起動時に当月の月表示を開く。前月・翌月へ移動、「今日」に戻るボタン
- 週の始まりは**月曜日**
- 各日のマスに表示するもの
  - 行った運動の種類（略称のチップ: BC / BA / BP / BS / 卓球 / バド / ヨガ / ラン / 登山 / プール / 他）
  - 右上に **その日の痛みの最大値** を数値で表示し、程度に応じて背景色を変える（0〜10 の段階色）
  - 記録がない日は何も表示しない。「痛みなし」で記録した日は「0」を表示する
- 日付をタップすると、その日の記録一覧を表示する
  - 一覧から各記録の編集・削除ができる
  - 「運動を記録」「痛みを記録」ボタンで、その日付の新規記録を作れる
- 画面右下の「＋」ボタンから、今日の日付で新規記録を作れる
- 週表示への切り替えは初版では作らない（将来検討）

**右上の数値は「最大値」を初期値とし、設定で「平均」に切り替えられる。** 最大値を初期値にする理由: 運動中だけ 7 だった日でも、他のタイミングが 0〜1 だと平均は 2〜3 になり、強い痛みが出た日を見落としやすい。カレンダーは「痛みが強く出た日を見つける」用途なので最大値がよい。設定で「平均」に切り替えられるようにする。

### 4.4 痛みセット（共通入力部品）

- 1 行 = 部位 ＋ 左右 ＋ 程度
- 「＋ 痛みを追加」で行を増やす。行ごとに削除できる
- 「痛みなし」ボタンを押すと行を隠して「痛みなし（0）」として保存する
- 何も入力していない状態は「未記入」とし、集計から除外する（「痛みなし = 0」とは区別する）

**部位（選択式）**
股関節 前（鼠径部） / 股関節 外側 / お尻 / 太もも 前 / 太もも 外側 / 太もも 内側 / 腰 / 膝 / その他
- 部位の一覧は設定画面で追加・並べ替え・非表示ができる

**左右**: 左 / 右 / 両方（前回入力した値を初期値にする）

**痛んだ動き（運動中の痛みだけ）**
- 運動中の痛みの各行（部位・左右・程度）で、その痛みが出た動きを複数選べる。例: 「股関節 前 6・ジャンプ」「お尻 3・キック」
- 初期候補: ジャンプ / キック / ランジ / スクワット / 開脚 / ひねり / 片脚立ち / ステップ昇降 / 切り返し / 着地 / 下り坂。設定で追加・削除できる

**程度: 0〜10 の数値評価スケール（NRS）**
医療機関でも使われる尺度なので、通院時に記録をそのまま見せやすい。0〜10 のボタンを横一列に並べ、1 タップで選べるようにする。目安を表示する。

| 数値 | 目安 |
|---|---|
| 0 | 痛みなし |
| 1〜3 | 軽い（気になるが動ける） |
| 4〜6 | 中くらい（動きを変えたくなる） |
| 7〜10 | 強い（運動を続けられない・日常生活に影響） |

**痛みの種類タグ（設定でオン／オフ、初期値オフ）**
- オンにすると、痛みの行ごとにタグを複数選べる。初期候補: ズキズキ / 鈍い / 引っかかる / 抜ける感じ / 張り
- タグの候補は設定で追加・削除できる

### 4.5 グラフ・分析

画面上部に期間（直近 30 日 / 90 日 / 全期間）と部位（全部位 / 部位ごと）のフィルタを 1 行で置く。

1. **サマリー**: 期間内の運動回数、痛みの平均（日ごとの最大値の平均）、痛み 7 以上の日数
2. **運動の種類別 痛みの平均**（横棒グラフ）
   - 種類ごとに「運動中」「運動後」「翌日」の 3 本を並べる
   - 各種類の回数（n）を表示し、少ないものは参考値と分かるようにする
   - 「運動後の痛みが最も高いのはボディアタック（平均 5.2）」のような一言の要約を出す
3. **痛みの推移**（折れ線グラフ）
   - 日ごとの痛みの最大値。運動した日は点で強調し、タップで運動の種類を表示
4. **強度別 運動後の痛み**（横棒グラフ）: 種類ごとに強度別の運動後の痛みを比べる。タップで翌日の値と回数を表示
   - 表示は「3 つにまとめる（抑えめ 1〜2 / ふつう 3 / 全力寄り 4〜5）」が初期値。グラフ上と設定で「5 段階」に切り替えられる
   - 3 回未満の値は薄く表示し「参考値」とする
5. **痛んだ動き**（横棒グラフ）: 動きごとの記録回数と、その痛みの程度の平均。表では動きごとに「どの部位が何回痛んだか」も出す。部位で絞り込むと、その部位が痛んだ動きだけを集計する
6. **週ごとの運動量と痛み**: 上段に週の運動時間（分）、下段に痛みの平均を、同じ週の並びで表示する（目盛りの違う 2 つの値を 1 つのグラフに重ねない）
7. **連日運動の影響**: 「前日も運動した日」と「間を空けた日」の翌日の痛みの平均を比べる
8. **部位別**（横棒グラフ）: 痛みが出た日数と平均の程度
9. **表で見る**: 各グラフの数値を表でも確認できる

**集計ルール**
- 1 つのタイミングに複数の痛みがある場合、そのタイミングの代表値は最大値とする（部位フィルタ時はその部位の値）
- 運動中: その運動の「運動中の痛み」
- 運動後: その運動記録の「運動後の痛み」。1 記録に複数種目がある場合は、含まれる全種目に同じ値を計上する
- 翌日: 運動した日の翌日の痛み記録（起床時を優先、なければその日の最大値）
- 未記入は集計しない。「痛みなし」は 0 として集計する

### 4.6 設定

- 運動の種類・部位の一覧の編集（追加・並べ替え・非表示）。非表示にしても過去の記録・グラフには残る
- 痛みの種類タグの使用（オン／オフ）と候補の編集
- 痛んだ動きの候補の編集
- 強度グラフの表示: 3 つにまとめる（初期値）/ 5 段階
- 「続けて追加」の目安時間（初期値 30 分）
- カレンダーの数値表示: 最大値 / 平均
- データのバックアップ: JSON 形式で書き出し・読み込み、CSV 書き出し（表計算ソフトで見る用）

## 5. 非機能要件

| 項目 | 内容 |
|---|---|
| オフライン | 通信なしで記録・閲覧・グラフ表示ができる |
| PWA | ホーム画面に追加でき、全画面で起動する。アイコン・起動画面を用意する |
| 操作性 | 片手で操作できる配置。1 件の記録が 30 秒程度で終わる |
| 表示 | スマホ幅（375px〜）を基本に、PC ではカレンダーとグラフを広く表示 |
| ダークモード | 端末の設定に合わせる |
| データ保護 | ブラウザの永続ストレージを要求する。最終バックアップから 30 日経つと書き出しを促す |
| 費用 | 0 円で運用 |

## 6. 技術構成

Laravel は学習目的で使う。アプリが Laravel なしでも動くように作り、Laravel は「自動バックアップ先」として後から足す 2 段階で進める。

### 6.1 第 1 段階: React の PWA ＋ スマホ内データベース

| 役割 | 技術 |
|---|---|
| 画面 | React + TypeScript + Vite |
| PWA | vite-plugin-pwa（Service Worker・manifest を自動生成） |
| データ保存 | IndexedDB（ライブラリ: Dexie.js） |
| グラフ | Recharts |
| 公開 | GitHub Pages または Cloudflare Pages（無料・HTTPS） |

- データをスマホ内に持つため、オフラインでも記録・グラフ表示がそのまま動く
- 機種変更への対応: 設定の「バックアップを書き出す」で JSON ファイルを iCloud Drive / Google ドライブ等に保存し、新しいスマホで「読み込む」
- 最終バックアップから 30 日経つと書き出しを促す

### 6.2 第 2 段階: Laravel API による自動バックアップ（学習用）

| 役割 | 技術 |
|---|---|
| API | Laravel（REST API） |
| 認証 | Laravel Sanctum のアクセストークン（利用者 1 名なので、発行したトークンをアプリの設定に 1 回入力するだけ。健康情報を他人に見られないために必要） |
| DB | MySQL または PostgreSQL |

- 通信できるときに、スマホ内で追加・変更された記録をサーバーへ送る（オフライン中の変更は通信が戻ったときに送る）
- 機種変更時は、新しいスマホでトークンを入力すればサーバーからデータを取り戻せる
- 学べること: API 設計、マイグレーション、認証、バリデーション、同期（更新日時による差分送信）
- 公開先: Laravel を無料で常時動かせるサービスは条件の変更が多いため、第 2 段階に入る時点で最新の無料枠を調べて決める。決まるまではローカル PC で動かして学習を進められる

### 6.3 データ量の見積もり

| 条件 | 量 |
|---|---|
| 1 件の記録 | 約 1KB |
| 1 日 3 件 × 365 日 | 約 1MB / 年 |
| 10 年分 | 約 10MB |

ブラウザの保存領域は通常数百 MB 以上使えるため、画像を扱わないこのアプリでは容量・表示速度とも問題にならない。

## 7. データ設計（端末内データベース）

```ts
// 運動記録
type ExerciseRecord = {
  id: string;
  kind: 'exercise';
  date: string;            // '2026-11-10'
  startTime?: string;      // '19:00'
  before: PainSet;
  activities: Activity[];  // 1 件以上
  after: PainSet;
  memo?: string;
  createdAt: string;
  updatedAt: string;
};

type Activity = {
  typeId: string;          // 'bodyattack' など
  otherName?: string;      // その他の場合の名称
  minutes: number;
  intensity: 1 | 2 | 3 | 4 | 5;     // 4.1.1 の 5 段階
  during: PainSet;
};

// 痛みのみの記録
type PainRecord = {
  id: string;
  kind: 'pain';
  date: string;
  timing: 'wake' | 'day' | 'night' | 'other';
  pain: PainSet;
  memo?: string;
  createdAt: string;
  updatedAt: string;
};

// 痛みセット
type PainSet = {
  none: boolean;           // true = 痛みなし（0）
  items: PainItem[];       // none=false かつ空 = 未記入
};

type PainItem = {
  partId: string;          // 'groin' など
  side: 'L' | 'R' | 'B';
  level: number;           // 0〜10
  tags?: string[];         // 痛みの種類タグ（設定でオンのとき）
  moves?: string[];        // 痛んだ動き（運動中の痛みだけ）
};

// 設定
type Settings = { calMode: 'max' | 'avg'; useTags: boolean; tags: string[]; moves: string[]; intView: '3' | '5'; gapMin: number; weekStart: 'mon' };

// マスタ（設定で編集）
type ExerciseType = { id: string; name: string; short: string; order: number; hidden: boolean };
type BodyPart     = { id: string; name: string; order: number; hidden: boolean };
```

## 9. 初版の範囲

**第 1 段階（初版）**: 1〜5 の全画面、PWA・オフライン、JSON バックアップ、痛みの種類タグ（設定でオン／オフ）、カレンダーの最大値／平均の切り替え、強度・痛んだ動きの記録、入力補助（よく使う組み合わせ・過去の傾向）、4.5 のグラフすべて
**第 2 段階**: Laravel API による自動バックアップ。あわせて検討: 翌朝の入力リマインド通知、気圧の自動記録、通院用レポート
**後回し**: 週表示、CSV 書き出し
**入れない**: 薬・セルフケアの記録
