# 環境構築手順（Windows）

このアプリを **パソコンで開発する（直す・機能を足す）** ための準備。
ふだん使うだけなら不要（公開 URL を iPhone の Safari で開き、ホーム画面に追加して使う）。

- 公開 URL: https://shibuya-mayu.github.io/pain-log/
- GitHub: https://github.com/shibuya-mayu/pain-log

---

## 1. 必要なソフトを入れる（最初の 1 回だけ）

スタートボタンを右クリック →「ターミナル」（または PowerShell）を開いて実行する。

```powershell
winget install OpenJS.NodeJS.LTS
winget install Git.Git
```

| ソフト | 役割 |
|---|---|
| Node.js | アプリを動かす・組み立てる |
| Git | GitHub に送る（GitHub へのログイン機能も入っている） |

`winget` が使えない場合は公式サイトからインストーラーを入れる。

- Node.js: https://nodejs.org/ （「LTS」版）
- Git: https://git-scm.com/download/win （設定はすべて初期値のままで良い）

インストールが終わったら **ターミナルを一度閉じて開き直す**。
入ったか確認する:

```powershell
node -v    # v22 以上ならOK
git --version
```

コミットに付く名前を設定する:

```powershell
git config --global user.name "shibuya-mayu"
git config --global user.email "GitHubに登録しているメールアドレス"
```

---

## 2. プロジェクトを用意する

### A. zip で受け取った場合（最初の 1 回だけ）

zip を `ドキュメント` などで展開し、GitHub に送る。

```powershell
cd $HOME\Documents\pain-log
git push -u origin main
```

初回はブラウザで GitHub のログイン画面が開くので、**shibuya-mayu** でサインインする。

### B. GitHub に送ったあと、別のパソコンで始める場合

```powershell
cd $HOME\Documents
git clone https://github.com/shibuya-mayu/pain-log.git
cd pain-log
```

---

## 3. アプリを起動する

```powershell
npm install     # 最初の 1 回だけ（部品のダウンロードに数分かかる）
npm run dev
```

ブラウザで **http://localhost:5180/** を開く。止めるときはターミナルで `Ctrl + C`。

- 開発中は、設定画面の一番下に「サンプルデータを入れる」が出る（公開版には出ない）
- 同じ Wi-Fi の iPhone からは、ターミナルに表示される `http://192.168.x.x:5180` で開ける
  （ホーム画面に追加・オフラインは公開版でしか動かない）

### よく使うコマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発用に起動する |
| `npm test` | 集計ロジックのテスト |
| `npm run lint` | コードのチェック |
| `npm run build` | 公開用のファイルを作る（型チェック込み） |

---

## 4. 直したものを公開する

```powershell
git add -A
git commit -m "直した内容を一言で"
git push
```

`push` すると GitHub Actions が自動でテスト・組み立て・公開をする（2〜3 分）。
進み具合は GitHub の **Actions** タブで見られる。緑のチェックが付けば公開完了。

### 最初の 1 回だけ: GitHub Pages の設定

GitHub のリポジトリ → **Settings** → 左メニュー **Pages** →
「Build and deployment」の **Source** を **GitHub Actions** にする（保存ボタンはなく、選んだ時点で設定される）。

## つまずきやすいところ

### 「このシステムではスクリプトの実行が無効になっているため…」と出る

PowerShell の安全設定。1 回だけ実行してから、もう一度試す。

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### 「Port 5180 is already in use」と出る

ほかのアプリが同じ番号を使っている。`vite.config.ts` の `5180` を別の数字（例: `5190`）に変える。

### `git push` で「Permission denied」「403」と出る

別の GitHub アカウントでログインしている。
「資格情報マネージャー」（Windows の検索で出てくる）→ Windows 資格情報 → `git:https://github.com` を削除して、もう一度 `git push` し、**shibuya-mayu** でサインインし直す。

### `git status` で全部のファイルが変更扱いになる

Mac で作ったファイルの改行コードの違いが原因のことがある。次を実行してから、もう一度 `git status` を見る。

```powershell
git config core.autocrlf input
```
